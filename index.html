API Endpoints

All endpoints return JSON. No authentication, no rate limits, no CORS restrictions.

GET /deities_list.json Master list of all 30 deities with type, origin, tags, and thumbnail URLs (English)
GET /{lang}/deities_list.json Localized deity list. Available for: en, pl, ua, bg, cz, sr
GET /{lang}/deities.json ⚡ Full bundle — all 30 deity objects in a single request. Best for apps loading all data at once.
GET /{lang}/deities/{id}.json Full details for a single deity. ID is zero-padded (001–030). Available in all 6 languages.
GET /search/{lang}.json Search-optimized flat index for client-side filtering by name, type, tags, domains, and origin.
GET /images/deities/{id}/thumbnail.png Deity thumbnail image (~160KB, PNG)
GET /images/deities/{id}/detailImage.png Full detail deity image (~2.3MB, PNG)

Parameters: {lang} — one of: en pl ua bg cz sr  |  {id} — zero-padded 3-digit string: 001 to 030

Code Examples

Copy-paste ready examples for common use cases.

// Base URL
const BASE = 'https://slavic-api.github.io/API';

// Load all 30 deities at once (recommended)
const { deities } = await fetch(`${BASE}/en/deities.json`).then(r => r.json());

// Get a single deity
const perun = await fetch(`${BASE}/en/deities/001.json`).then(r => r.json());

// Ukrainian version
const perunUA = await fetch(`${BASE}/ua/deities/001.json`).then(r => r.json());

// Client-side filtering
const gods = deities.filter(d => d.type === 'god');
const warriors = deities.filter(d => d.tags.includes('warrior'));
const eastSlavic = deities.filter(d => d.origin.includes('East Slavic'));
import httpx

BASE = "https://slavic-api.github.io/API"

# Load all 30 deities at once
resp = httpx.get(f"{BASE}/en/deities.json")
deities = resp.json()["deities"]

# Single deity
perun = httpx.get(f"{BASE}/en/deities/001.json").json()

# Filter by type
gods = [d for d in deities if d["type"] == "god"]

# Filter by origin
west_slavic = [d for d in deities
               if "West Slavic" in d["origin"]]
let base = "https://slavic-api.github.io/API"

// Decodable models
struct DeitiesBundle: Decodable {
    let lang: String
    let total: Int
    let deities: [Deity]
}

// Fetch all deities
let url = URL(string: "\(base)/en/deities.json")!
let (data, _) = try await URLSession.shared.data(from: url)
let bundle = try JSONDecoder().decode(DeitiesBundle.self, from: data)

// Fetch single deity in Ukrainian
let perunURL = URL(string: "\(base)/ua/deities/001.json")!

Data Schema

Every deity object follows this schema. Localized fields are translated per language; structural fields stay in English.

FieldTypeDescription
idstringZero-padded 3-digit identifier ("001"–"030")
namestringLocalized deity name
alternateNamesstring[]Historical names across Slavic cultures (original languages)
typestringClassification in English: god, goddess, spirit, deity, creature, personification, deity pair, primordial god, mythical place
originstring[]Slavic tradition(s): "East Slavic", "West Slavic", "South Slavic"
descriptionstringShort localized description (1–2 sentences)
mythologystringFull localized mythology narrative (3–6 sentences)
attributes.Domainsstring[]Areas of divine influence (localized)
attributes.Symbolsstring[]Sacred symbols (localized)
attributes.Sacred Animalsstring[]Animals associated with the deity (localized)
attributes.Sacred Plantsstring[]Plants associated with the deity (localized)
attributes.ElementstringPrimary element (localized)
relationshipsobjectrivals[], family[], allies[] — arrays of deity IDs
worship.regionsstring[]Geographic regions of worship (English country names)
worship.festivalsstring[]Festivals and holy days (localized, dates preserved)
worship.offeringsstring[]Traditional offerings (localized)
tagsstring[]API filtering tags in English (e.g. "warrior", "major deity", "Kiev pantheon")
thumbnailUrlstringRelative path to thumbnail PNG (~160KB)
detailImageUrlstringRelative path to full detail PNG (~2.3MB)
